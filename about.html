Our Mission

🎯 Why We Built This

Many rural school students interact with computers for the very first time in school labs. Complex menus, English jargon, and heavy web applications can feel intimidating.

This portal provides an accessible, step-by-step foundation covering basic hardware, mouse precision, typing, and digital safety without requiring internet access, logins, or database setup.

👨‍🏫 Guide for Teachers & Volunteers

Here is the recommended schedule to guide students through this curriculum:

  1. Physical Inspection (Day 1): Let students press the CPU power button, trace the mouse cable, and turn on the monitor before opening any software.
  2. Mouse Precision (Day 2): Guide learners through Module 2 and the Practice Lab to master left-clicks and dragging.
  3. Folder Organization (Day 3): Have each student create a folder on the Desktop named with their Roll Number.
  4. Typing Exercise (Day 4): Instruct students to type 3 sentences about their village or favorite animal and save the document.
  5. Evaluation (Day 5): Open the final Quiz section on each computer or on a single teacher laptop to record scores via Google Forms.

⚙️ Offline Classroom Setup

This entire platform is built with lightweight, zero-dependency HTML, CSS, and vanilla JavaScript:

  • No Internet Required: Copy the project folder to each computer via a USB drive. Double-click index.html to run it in any browser (Chrome, Firefox, Edge).
  • No Login Hassle: Students do not need email accounts or passwords to access the modules.
  • Quiz Note: The final Google Form test requires an active internet connection only during submission.
